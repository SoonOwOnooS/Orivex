# Orivex

[English](README.en.md) · [访问网站](https://orivex.real-videogame.workers.dev/)

## 目的

Orivex 希望帮助玩家找到并支持热爱游戏创作的开发者，让游戏背后的人、故事和设计思想更容易被看见。

这个想法源于对游戏被快速模仿的担忧。我们希望通过保存创作者的公开记录与创作轨迹，让玩家了解一款游戏如何诞生，并找到自己愿意关注和支持的作品。

## 计划内容

以下是项目计划发展的方向：

1. **创作故事**：开发者为什么做这款游戏，灵感来自哪里，设计经历了哪些变化。
2. **证据时间线**：整理社交帖子、开发日志与首次展示，为日期附上来源，并允许补充和更正。计划让使用 GitHub 登录的用户核对这些记录，帮助呈现最早已知的公开时间。
3. **同人文化**：为游戏或系列建立同人专区，汇集二创作品，保留创作者与原始链接，并区分官方内容和同人作品。

希望玩家能够通过社区分享来到 Orivex，了解游戏的创作故事、设计思想与同人文化，再决定支持哪些作品和创作者。
